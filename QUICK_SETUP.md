# Quick Setup for New Conversations

## 🚀 One-command Setup (Recommended)

```bash
npm init -y && npm install sharp
```

---

## 📦 Manual Package.json Template

If you want to manually create package.json:

```json
{
  "name": "my-project",
  "version": "1.0.0",
  "dependencies": {
    "sharp": "^0.34.5"
  }
}
```

Then run:
```bash
npm install
```
